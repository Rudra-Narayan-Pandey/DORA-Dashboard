# DORA Metrics Telemetry Command Center

A production-quality SaaS dashboard designed with a futuristic AI operating system aesthetic (inspired by Apple Vision Pro, JARVIS, Tron Legacy, and NASA Mission Control). It monitors DevOps health using the four key DORA metrics.

## Tech Stack
- **React 19 (Vite)**
- **Tailwind CSS v3** (PostCSS & Autoprefixer)
- **React Router DOM v6**
- **Framer Motion** (HUD slide, scale, and visionOS blurs)
- **Recharts** (Neon-glowing area, line, composed, and donut charts)
- **React Hot Toast** (Custom glassmorphic alert notifications)
- **React Icons** (Glyphs and symbols)
- **Day.js** (Timestamps and durations)
- **Axios** (Service integrations ready for backend connection)

## Quick Start

### 1. Install dependencies
```bash
npm install
```

### 2. Launch local dev grid
```bash
npm run dev
```

### 3. Verify production compilation
```bash
npm run build
```
